# Support

## Before asking for help

Check the [project README](README.md), the [documentation index](docs/README.md), and the search benchmark guide. Confirm that dependencies are installed, `.env` is based on `.env.example`, and the selected storage services are healthy.

## Bug reports

Use an issue for a reproducible bug. Include:

- the commit or release;
- operating system and Python version;
- the exact command;
- the strategy and dataset name;
- relevant configuration names with all secrets removed;
- the complete error message and a minimal reproduction.

Do not paste API keys, passwords, private service addresses, absolute local paths, or generated result files.

## Questions and proposals

Use discussions for usage questions, architecture proposals, and experiment design. A focused issue is preferable when a documentation correction or concrete bug can be described independently.

For security concerns, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
